# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-02

Полная переработка по итогам [аудита](AUDIT.md).

### Добавлено

- Живой статус «Открыто до 23:00 / Закрыто, откроется завтра в 09:00» по ташкентскому времени.
- Маршрут в Яндекс Картах, копирование адреса с координатами для такси.
- Карта Google по кнопке: со скелетоном загрузки, ошибкой и повтором.
- Тёмная тема, страница 404, превью для соцсетей, данные schema.org, `sitemap.xml`, `robots.txt`.
- Единый файл данных о ресторане с проверкой при сборке.
- Юнит-тесты, браузерные тесты, автоматическая проверка доступности (WCAG 2.2 AA), Lighthouse CI.
- Линтеры, форматтер, проверка типов, GitHub Actions, деплой на GitHub Pages, Dependabot.
- README, лицензия, этот файл.

### Изменено

- Новый дизайн: собственная дизайн-система на токенах, шрифты Alegreya и Alegreya Sans, палитра с одним акцентом, асимметричная сетка.
- Все тексты переписаны: короче, конкретнее, без клише.
- Рейтинг показан как есть (3,6), а не округлён до четырёх звёзд. Имена авторов отзывов сокращены.
- Сайт собирается Eleventy из шаблонов вместо одного HTML-файла.

### Удалено

- Градиентные прямоугольники на месте фотографий и раздел «Галерея».
- Эмодзи вместо иконок.
- Маркетинговые цифры «500+ счастливых семей» и «100% домашних рецептов», упоминание доставки.
- Загрузка шрифтов и карты со сторонних серверов при открытии страницы.

### Исправлено

- Невидимая кнопка «Смотреть меню» на первом экране.
- Ссылка «Все отзывы» вела на главную Google Maps.
- Закрытое мобильное меню оставалось доступным с клавиатуры.
- На телефоне не было быстрого способа позвонить.

## [0.1.0] — 2026-06-17

- Первая версия: одностраничный сайт на HTML, CSS и JavaScript.
